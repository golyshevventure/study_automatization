# Страница деталей курса с модулями

**Дата:** 2026-05-31
**Контекст:** После реализации раздела «Мои курсы» с реальными данными, следующий логичный шаг — дать пользователю возможность «провалиться» в конкретный курс и увидеть его содержание (модули с прогрессом), а также перейти к обучению на Netology.

## Что сделано

### 1. Backend — endpoint для одного курса

**Файл:** `backend/api/programs_router.py`

**Новый endpoint:** `GET /api/programs/{program_id}`

```python
@router.get("/programs/{program_id}", response_model=CourseResponse)
async def get_program(
    program_id: int,
    session: UserSession = Depends(get_current_session),
):
    """Вернуть одну активную программу по ID с прогрессом."""
    service = NetologyProgramsService()
    courses = service.get_active_courses(session.cookies_json)
    for course in courses:
        if course["id"] == program_id:
            return course
    raise HTTPException(status_code=404, detail="Курс не найден")
```

**Зачем отдельный endpoint:**
- Прямой заход по URL `/course/59690` работает (F5, ссылка из закладок)
- REST-конвенция — получение одного ресурса по ID
- В будущем можно расширить (описание курса, даты, дедлайны по модулю)

### 2. Backend — ссылки на модули в Netology

**Файл:** `backend/services/netology_programs_service.py`

**Расширен формат модуля:** добавлено поле `link` — полный URL на модуль в Netology.

```python
# Для профессий — каждый модуль со своей ссылкой
path = m.get("program_schedule_path", "")
link = f"{NETOLOGY_BASE}{path}" if path else None
modules.append({
    "title": m.get("title", "Без названия"),
    "progress": _module_progress(m),
    "link": link,
})
```

**Для обычных курсов (не профессий) — временное решение:**

> ⚠️ **Это хуйня и надо будет доработать.**

Пользователь попросил: «Давай пока сделаем так, чтобы показывался один модуль с названием самого курса и прогрессом по нему. И также при клике переход на нетологию».

Реализовано:
```python
# Для обычных курсов показываем один модуль — сам курс
path = raw_modules[0].get("program_schedule_path", "") if raw_modules else ""
link = f"{NETOLOGY_BASE}{path}" if path else None
modules = [{
    "title": progress_data.get("title", "Без названия"),
    "progress": progress,
    "link": link,
}]
```

**Проблема:** У курса может быть несколько модулей (например, вводный + основной). Сейчас мы показываем только один «виртуальный» модуль с названием курса. В будущем нужно:
- Показывать реальные модули курса
- Или понять логику Netology: что считать «модулем» для курса vs профессии

**Реальные данные (пример):**
```json
{
  "title": "Адаптационный модуль для бакалавриата...",
  "progress": 96,
  "link": "https://netology.ru/profile/program/bhebfad-25-am-1/schedule"
}
```

### 4. Frontend — hook `useCourse.ts`

**Файл:** `frontend/src/hooks/useCourse.ts`

```typescript
export function useCourse(programId: string | undefined) {
  const [course, setCourse] = useState<Course | null>(null);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState<string | null>(null);

  useEffect(() => {
    fetch(`http://localhost:8000/api/programs/${programId}`, {
      credentials: "include",
    })
      .then(...)
      .then((data: Course) => { setCourse(data); setLoading(false); })
      .catch((err) => { setError(err.message); setLoading(false); });
  }, [programId]);

  return { course, loading, error };
}
```

## Архитектура потока данных

```
Пользователь кликает на CourseCard в Home
    ↓
navigate(/course/59690)
    ↓
CourseDetail монтируется
    ↓
useCourse("59690") → GET /api/programs/59690 (with credentials)
    ↓
FastAPI → get_current_session (JWT из cookie)
    ↓ SELECT
PostgreSQL → UserSession (cookies_json)
    ↓
NetologyProgramsService.get_active_courses(cookies_json)
    ↓
GET /calendar/filters + GET /programs/progress (Netology)
    ↓
Мерж, расчёт прогресса, формирование ссылок
    ↓
JSON {id, title, type, progress, passed, modules: [{title, progress, link}]}
    ↓
CourseDetail отображает шапку + список модулей
    ↓
Пользователь кликает на ModuleCard
    ↓
<a href="https://netology.ru/profile/program/..." target="_blank">
    ↓
Открывается модуль на Netology в новой вкладке
```

## Технический долг (что надо доработать)

### 🔴 Модули для обычных курсов
Сейчас для курсов (не профессий) создаётся один «виртуальный» модуль с названием курса. Это временное решение, потому что:
- У курсов на Netology тоже могут быть несколько модулей
- Пользователь видит только один модуль и не понимает структуру курса

**Решение:** Исследовать структуру `/programs/progress` для курсов и решить: показывать реальные модули или оставить логику «один модуль = один курс».

### 🟡 Навигация «Назад»
Сейчас `navigate(-1)` — просто шаг назад в истории браузера. Если пользователь зашёл по прямой ссылке — вернётся на предыдущий сайт, а не на Home.

**Решение:** Использовать `navigate("/")` или проверять `location.state?.from`.

### 🟡 Свайп-жест
Запланирован, но не реализован. Можно добавить через библиотеку `react-swipeable` для мобильного UX.
