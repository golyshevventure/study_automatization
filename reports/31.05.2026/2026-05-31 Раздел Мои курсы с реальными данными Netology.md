### 1. Исследование структуры API Netology `/programs/progress`

**Проблема:** В отчёте 28.05 утверждалось, что `/programs/progress` содержит поле `progress_percent`. Реальный запрос показал, что это поле **отсутствует**.

**Реальная структура ответа:**
```json
{
  "programs": [{
    "id": 59690,
    "title": "Бакалавриат «Финансы и анализ данных»...",
    "is_profession": true,
    "modules": [{
      "id": 123,

      "lessons_passed": 0,
      "lessons_count": 0,
      "is_passed": false,
      "is_available": true

```

**Ключевые поля для расчёта прогресса:**
- `lesson_items_passed` — сколько элементов уроков пройдено
- `lesson_items_count` — сколько элементов уроков всего

**Баг:** `NetologyProgramsService` использовал `progress_data.get("progress_percent", 0)`, что приводило к `KeyError` (поле отсутствовало на уровне программы).

### 2. Исправлен `NetologyProgramsService` (backend)

**Файл:** `backend/services/netology_programs_service.py`

**Добавлены функции расчёта прогресса:**

```python
def _calc_progress(passed: int, total: int) -> int:
    """Вычислить процент прогресса."""
    if total <= 0:
        return 0
    return int(round(passed / total * 100))


def _module_progress(module: dict) -> int:
    """Прогресс модуля из lesson_items."""
    return _calc_progress(
        module.get("lesson_items_passed", 0),
        module.get("lesson_items_count", 0),
    )


def _program_progress(program: dict) -> int:
    """Прогресс программы = суммарный прогресс по lesson_items всех модулей."""
    modules = program.get("modules", [])
    total_passed = sum(m.get("lesson_items_passed", 0) for m in modules)
    total_count = sum(m.get("lesson_items_count", 0) for m in modules)
    return _calc_progress(total_passed, total_count)
```

**Логика `get_active_courses()` изменена:**
- Прогресс программы считается как сумма `lesson_items_passed / lesson_items_count` по всем модулям
- Прогресс каждого модуля считается отдельно
- `passed = progress == 100`

**Результат:**
```
Профессия: Бакалавриат «Финансы и анализ данных»... progress=62%
Профессия: Основы анализа данных в SQL, Python... progress=1%
```

### 4. Frontend — `usePrograms()` hook

**Файл:** `frontend/src/hooks/usePrograms.ts`

```typescript
export interface CourseModule {
  title: string;
  progress: number;
}

export interface Course {
  id: number;
  title: string;
  type: string;
  progress: number;
  passed: boolean;
  modules: CourseModule[];
}

export function usePrograms() {
  const [courses, setCourses] = useState<Course[]>([]);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState<string | null>(null);

  useEffect(() => {
    fetch("http://localhost:8000/api/programs", {
      credentials: "include",
      headers: { Accept: "application/json" },
    })
      .then(async (res) => {
        if (!res.ok) {
          const data = await res.json().catch(() => ({}));
          throw new Error(data.detail || `HTTP ${res.status}`);
        }
        return res.json();
      })
      .then((data: Course[]) => { setCourses(data); setLoading(false); })
      .catch((err) => { setError(err.message); setLoading(false); });
  }, []);

  return { courses, loading, error };
}
```

## Архитектура потока данных

```
Пользователь открывает Home
    ↓
Frontend → usePrograms() → GET /api/programs (with credentials)
    ↓
FastAPI → get_current_session (JWT из cookie)
    ↓ SELECT
PostgreSQL → UserSession (cookies_json)
    ↓
NetologyProgramsService.get_active_courses(cookies_json)
    ↓
GET /backend/api/user/programs/calendar/filters → {programs: [{id}]}
    ↓
GET /backend/api/user/programs/progress → {programs: [{modules: [{lesson_items_passed, lesson_items_count}]}]}
    ↓
Мерж: active_ids + progress_data
    ↓
Расчёт прогресса (lesson_items_passed / lesson_items_count)
    ↓
JSON [{id, title, type, progress, passed, modules}]
    ↓
Frontend → отображение в Home
```

## Баги и их решение

### Баг: `KeyError: 'progress_percent'`
**Причина:** Поле `progress_percent` отсутствует в ответе `/programs/progress` как на уровне программы, так и на уровне модуля.

**Решение:** Прогресс считается из `lesson_items_passed / lesson_items_count`.

### Баг: Uvicorn не подхватывал изменения
**Причина:** `--reload` не всегда обновляет глубоко вложенные модули, особенно если используются глобальные инстансы.

**Решение:** Полный restart uvicorn (kill + restart).
