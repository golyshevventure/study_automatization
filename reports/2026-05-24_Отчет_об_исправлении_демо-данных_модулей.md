# Отчет об исправлении демо-данных модулей профессий

## Дата: 2026-05-24

---

## Проблема

В компоненте `Home.tsx` демо-данные для профессий содержали **сокращенный вручную составленный список модулей** вместо реальных данных из API Нетологии.

| Программа | Было в демо | Реальность (API) | Расхождение |
|-----------|-------------|------------------|-------------|
| Data Scientist: с нуля до middle | 8 модулей | **23 модуля** | −15 |
| DevOps-инженер с нуля | 8 модулей | **25 модулей** | −17 |
| Бакалавриат «Финансы и анализ данных» | 8 модулей | **23 модуля** | −15 |
| Основы анализа данных | 5 модулей | **5 модулей** | 0 (совпало) |

В результате на UI везде отображалось `+3` оставшихся модуля, что вводило в заблуждение.

---

## Источник данных

Скрипт `Тесты/test_my_programs_and_progress.py` выполнил запрос:
```
GET /backend/api/user/programs/progress
```

Результат сохранён в:
```
Данные/my_programs_progress.json (38 KB)
```

---

## Исправление

Демо-массив `myCourses` в `frontend/src/pages/Home.tsx` полностью заменён на данные из реального API-ответа.

### Общий прогресс профессий (по API)

| Программа | Модулей | Прогресс |
|-----------|---------|----------|
| Бакалавриат «Финансы и анализ данных» | 23 | **62%** (939/1518 материалов) |
| Data Scientist: с нуля до middle | 23 | **0%** |
| DevOps-инженер с нуля | 25 | **0%** |
| Основы анализа данных | 5 | **1%** (1/156) |

### Пройденные модули (по API)

Из 23 модулей бакалавриата полностью пройден **1 модуль**:
- ✅ «Финансовый университет: история и современность» (12/12)

Остальные модули в работе (от 7% до 96% по материалам).

Теперь карточки профессий отображают:
- **5 коротких полосок** первых модулей
- **+18**, **+20**, **+18** — фактическое количество оставшихся модулей
