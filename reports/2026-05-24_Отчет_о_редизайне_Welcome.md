## 1. Логотип

- **Источник:** `frontend/src/pages/logo/logo_v4_white_mono.png`

- **Отступ до заголовка:** регулируется через `mb-{N}` в Welcome.tsx (строка 36)

## 2. Типографика

- **Весь текст:** `JetBrains Mono` (monospace)
- **Заголовки:** перешли с `Inter` на `JetBrains Mono` (убран override в `index.css`)
- **Импорт шрифта:** добавлен в `index.css`

## 3. Фон страницы

- **Базовый цвет:** `#020617` (slate-950)
- **Эффект:** два радиальных градиента — фиолетовые пятна света в углах:
  - Верхний левый: `circle at 10% 10%, rgba(138, 43, 226, 0.25)`
  - Нижний правый: `circle at 90% 90%, rgba(138, 43, 226, 0.15)`

## 4. Заголовок StudyCore

- **Цвет:** белый (`#fff`)
- **Свечение:** `text-shadow: 0 0 10px rgba(138, 43, 226, 0.5), 0 0 20px rgba(0, 240, 255, 0.3)`
- **Размер:** `text-5xl font-bold`

## 5. Карточки фич (4 шт.)

- **Фон:** `rgba(15, 23, 42, 0.6)`
- **Свечение (статичное):** `box-shadow: 0 0 15px rgba(0, 240, 255, 0.3), 0 0 5px rgba(138, 43, 226, 0.3)`
- **Отступы между карточками:** `gap-[17px]` (увеличены на 5px)
- **Анимация эмодзи:** hover/active эффекты (`write`, `stack`, `alarm`, `bell`)
- **Динамическая пульсация:** убрана (оставлено только статичное свечение)

## 6. Кнопки

- **Цвет:** фиолетовый `#8a2be2` (без градиента)
- **Свечение кнопки:** многослойный `box-shadow`:
  - `0 0 10px rgba(138, 43, 226, 0.6)`
  - `0 0 20px rgba(138, 43, 226, 0.3)`
  - `0 0 40px rgba(0, 240, 255, 0.2)`
- **Свечение текста:** `text-shadow: 0 0 5px rgba(255,255,255,0.5)`

## 7. Форма авторизации

- **Заголовок:** «Вход в Нетологию» — белый, с неоновым свечением
- **Поля ввода:** полупрозрачный фон `rgba(255,255,255,0.15)`
- **Кнопка «Войти»:** фиолетовая с неоновым свечением (активна только при заполненных полях)
- **Текст безопасности:** `🔒 Ваши данные под надежной защитой. Подробнее`
- **Расположение:** в одну строку (`whitespace-nowrap`)

## 8. Dev-окружение

- **Проблема:** Vite не подхватывал изменения файлов при редактировании из VS Code (WSL + OneDrive)
- **Решение:** добавлен `usePolling: true` в `vite.config.ts`
  ```ts
  server: {
    watch: { usePolling: true, interval: 500 }
  }
  ```
- **Результат:** HMR обновляет страницу в течение 1–2 секунд после сохранения
