## 🔥 Активные проблемы (приоритеты)

### P0 — Блокирует качество конспектов

1. **Audio fallback threshold bug**
   - HTML fallback возвращает ~4800 символов "структуры курса"
   - Порог `len(text) < 1000` → audio fallback НИКОГДА не срабатывает для вебинаров без VTT
   - Результат: бесполезные конспекты из плана вместо транскрипций
   - **Решение:** проверять наличие видео (MP4/M3U8) напрямую → если видео есть, ВСЕГДА транскрибируем

2. **Классификация: "всё с видео = конспект"**
   - Текущий классификатор смотрит на название раздела ("вебинар"/"лекция")
   - Тема 1-10 содержат видео, но название раздела — "Тема N", не "вебинар"
   - Результат: видео-лекции классифицируются как "учебные материалы" вместо конспектов
   - **Решение:** если в разделе есть видео → весь раздел = конспект

3. **Объединение материалов раздела**
   - Одно занятие (lesson) может содержать 2-3 материала (lesson_items)
   - Например, Тема 1 = "часть 1" (видео) + "часть 2" (видео) + "вопросы для самоконтроля"
   - Сейчас каждый item обрабатывается отдельно → 3 отдельных файла
   - **Решение:** объединять все материалы одного раздела в один конспект
   - Исключение: "Рабочая программа" (PDF) и "Критерии оценивания" — разные категории

### P1 — Скорость

4. **`sleep(10)` между материалами**
   - ~33 материала × 10с = 5.5 минут чистого ожидания
   - **Решение:** `sleep(3)` + параллельная загрузка контента (asyncio.gather)

5. **Параллельные API-запросы**
   - OpenRouter DeepSketch: ~3-5 parallel requests
   - **Решение:** rate-limited semaphore для API calls

### P2 — Мониторинг качества

6. **Нет проверки содержимого конспектов**
   - Ассистент считает файлы, но не проверяет качество
   - **Решение:** post-generation check — длина, наличие ключевых секций
