# Решение: Модуль авторизации Netology (без Playwright)

**Дата:** 2026-05-29
**Контекст:** Исследование YetAnotherCalendar подтвердило, что Netology поддерживает авторизацию через POST /backend/api/user/sign_in без браузера. StudyCore переходит на FastAPI backend.

---

## Что решено

1. **Отказ от Playwright для авторизации**
   - Ранее: Playwright запускал Chromium, открывал форму логина, вводил email/password, ждал загрузки cookies.
   - Теперь: один HTTP POST-запрос, 200–300 мс, cookies в ответе.

2. **Создание модуля `backend/auth_service/`**
   - `NetologyAuthService` — класс для авторизации
   - `NetologyAuthError` — кастомное исключение
   - Модуль НЕ сохраняет и НЕ логирует credentials
   - Модуль НЕ выводит cookies в stdout/stderr (только возвращает)

---

## Архитектура

```
backend/auth_service/
├── __init__.py          # Экспорт NetologyAuthService, NetologyAuthError
└── netology_auth.py     # Реализация
```

### Класс `NetologyAuthService`

| Метод | Аргументы | Возвращает | Исключения |
|-------|-----------|-----------|------------|
| `authenticate(email, password)` | `str, str` | `httpx.Cookies` | `NetologyAuthError` |

### Поток данных

```
Пользователь
    ↓ email + password
NetologyAuthService.authenticate()
    ↓ POST /backend/api/user/sign_in
Netology.ru
    ↓ 200 + Set-Cookie
NetologyAuthService
    ↓ httpx.Cookies
Вызвавший код
```

### Что делает модуль

- ✅ Отправляет POST с `login`, `password`, `remember=1`
- ✅ Возвращает `httpx.Cookies` с `_netology-on-rails_session`
- ✅ Обрабатывает 401 (неверные credentials)
- ✅ Обрабатывает сетевые ошибки
- ✅ Обрабатывает неожиданные HTTP-статусы

### Чего НЕ делает модуль

- ❌ НЕ сохраняет cookies в файл
- ❌ НЕ логирует email/password
- ❌ НЕ выводит cookies в stdout/stderr
- ❌ НЕ хранит state между вызовами
- ❌ НЕ обновляет просроченные cookies

---

## Почему именно так

### Скорость

| Метод | Время |
|-------|-------|
| Playwright + Chromium | 10–15 секунд |
| HTTP POST /sign_in | 200–300 мс |

### Надёжность

| Метод | Точки отказа |
|-------|--------------|
| Playwright | headless-детекция, race conditions, WSL-проблемы, обновления Chromium |
| HTTP POST | только сеть и сервер Netology |

### Безопасность

- Credentials передаются только в теле POST-запроса (HTTPS)
- Модуль НЕ сохраняет пароль в памяти после вызова
- Модуль НЕ логирует sensitive данные

## FastAPI endpoint

### Файлы

```
backend/
├── main.py              # FastAPI app с CORS
└── api/
    └── auth_router.py   # POST /api/auth/netology
```

### Endpoint: POST /api/auth/netology

| Поле запроса | Тип | Описание |
|-------------|-----|----------|
| `email` | `str` | Email от аккаунта Netology |
| `password` | `str` | Пароль от аккаунта Netology |

| Ответ | Код ошибки | Сценарий |
|-------|-----------|----------|
| `{success: true}` | — | Авторизация успешна |
| `{success: false, error: "invalid_credentials"}` | 401 | Неверный логин/пароль |
| `{success: false, error: "network_error"}` | timeout | Сетевая ошибка |

### Что делает endpoint

- ✅ Принимает email/password через Pydantic-схему `AuthRequest`
- ✅ Вызывает `NetologyAuthService.authenticate()`
- ✅ При 200 → возвращает `{success: true}`
- ✅ При 401 → возвращает `{success: false, error: "invalid_credentials"}`
- ✅ При timeout → возвращает `{success: false, error: "network_error"}`
- ✅ НЕ сохраняет cookies в файл/БД
- ✅ НЕ логирует credentials
- ✅ НЕ возвращает cookies фронтенду (только статус)

## Интеграция с фронтендом

### Welcome.tsx

При нажатии кнопки "Войти" выполняется:

```
Пользователь вводит email + password
    ↓ нажимает "Войти"
Welcome.tsx — fetch POST http://localhost:8000/api/auth/netology
    ↓ JSON с email и password
FastAPI backend — auth_router.py
    ↓ вызывает NetologyAuthService.authenticate()
Netology.ru — POST /sign_in
    ↓ ответ
FastAPI backend
    ↓ JSON {success: true/false, error: "..."}
Welcome.tsx
    ↓ success=true  → navigate("/")
    ↓ success=false → показать красный текст ошибки
```

### Состояния ошибок

| Сценарий | Текст ошибки | Расположение |
|----------|-------------|--------------|
| 401 от Netology | "Неверный логин или пароль" | Между заголовком и полем email |
| Сетевая ошибка | "Ошибка авторизации. Попробуйте ещё раз" | Между заголовком и полем email |

### UI-элементы

- **Спиннер** на кнопке "Войти" при `isLoading=true` (CSS-анимация вращения)
- **Disabled** поля ввода и кнопка при загрузке
- **Кнопка "Назад"** — сбрасывает форму, ошибку и возвращает на экран приветствия
