# Решение: Оптимизация LLM-генерации конспектов

**Дата:** 2026-05-24
**Контекст:** API-first прогон дисциплины "Введение в специальность" показал, что bottleneck сместился с сбора контента на LLM-генерацию. Тема 5 (180K символов) требовала ~15 минут только на LLM.

**Принятое решение:** Внедрить пункты 1, 2, 3 из предложенных идей оптимизации.

---

## Пункт 1: Параллельная отправка chunks

**Что:** Отправлять все chunks одной темы в LLM одновременно, а не последовательно.

**Как:** Использовать `concurrent.futures.ThreadPoolExecutor` внутри синхронной `generate_summary()`. Каждый chunk обрабатывается в отдельном потоке через `generate_chunk()`.

**Ожидаемый эффект:** Ускорение пропорционально количеству chunks. Для 3 chunks — ~3x быстрее (с ~15 до ~5 минут).

**Почему ThreadPoolExecutor, а не asyncio:** `generate_summary` вызывается из sync-контекста (`process_material`), а также из async-функций через прямой вызов. `ThreadPoolExecutor` работает в обоих случаях без конфликтов с event loop.

---

## Пункт 2: Увеличение CHUNK_SIZE

**Что:** Поднять `CHUNK_SIZE` с 70000 до 100000.

**Почему 100000:** deepseek-v3.2 поддерживает 128K контекст. 100K оставляет запас на system prompt и выходной текст. Ранее 70K был выбран консервативно.

**Ожидаемый эффект:** Тема 180K символов упадёт с 3 chunks до 2. Минус один LLM-запрос.

---

## Пункт 3: Убрать time.sleep(15)

**Что:** Удалить `time.sleep(15)` перед каждым запросом в `generate_chunk` и между chunks в `generate_summary`.

**Почему:** Эти задержки были добавлены для избежания rate limiting, но OpenRouter для deepseek допускает достаточно высокий RPM. Параллельная отправка 2-3 запросов не вызывает проблем.

**Ожидаемый эффект:** Экономия 15-45 секунд на тему.

---

## Пошаговый план внедрения

1. **Изменить `generate_summary.py`:**
   - Импортировать `concurrent.futures`
   - Изменить `CHUNK_SIZE = 100000`
   - Убрать `time.sleep(15)` из `generate_chunk()`
   - В `generate_summary()` заменить цикл `for chunk in chunks` на `ThreadPoolExecutor.map()`
   - Убрать `time.sleep(15)` между chunks

2. **Синтаксическая проверка:** `python -m py_compile generate_summary.py`

3. **Отчёт о внедрении** в `reports/`

4. **Прогон НЕ запускать** без указания пользователя.
