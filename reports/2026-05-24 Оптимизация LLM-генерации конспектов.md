# Отчёт: Оптимизация LLM-генерации конспектов

**Дата:** 2026-05-24
**Контекст:** API-first прогон дисциплины "Введение в специальность" (program_id: `bhebfad-25-vvs-2`) выявил, что LLM-генерация стала главным bottleneck. Тема 5 (180K символов) требовала ~15 минут только на генерацию конспекта.

**Решение:** Внедрены пункты 1, 2, 3 из списка идей оптимизации.

---

## Что было сделано

### 1. Параллельная отправка chunks

**Файл:** `generate_summary.py`

Заменён последовательный цикл обработки chunks на `concurrent.futures.ThreadPoolExecutor`. Все chunks одной темы отправляются в LLM одновременно в отдельных потоках.

```python
with concurrent.futures.ThreadPoolExecutor(max_workers=len(chunks)) as executor:
    futures = {
        executor.submit(generate_chunk, chunk, subject, topic): i
        for i, chunk in enumerate(chunks)
    }
    results = [None] * len(chunks)
    for future in concurrent.futures.as_completed(futures):
        ...
```

**Ожидаемый эффект:** Ускорение пропорционально количеству chunks. Для 3 chunks — ~3x быстрее (с ~15 до ~5 минут).

### 2. Увеличение CHUNK_SIZE

**Файл:** `generate_summary.py`

`CHUNK_SIZE` поднят с `70000` до `100000`.

**Обоснование:** Модель deepseek-v3.2 поддерживает 128K контекст. 100K оставляет запас на system prompt и выходной текст. При 70K тема в 180K символов разбивалась на 3 части, при 100K — на 2.

**Ожидаемый эффект:** Минус один LLM-запрос для крупных тем.

### 3. Убраны принудительные задержки

**Файл:** `generate_summary.py`

Удалены:
- `time.sleep(15)` перед каждым запросом в `generate_chunk()`
- `time.sleep(15)` между chunks в `generate_summary()`

**Обоснование:** Задержки добавлялись для избежания rate limiting, но OpenRouter для deepseek допускает достаточно высокий RPM. Параллельная отправка 2-3 запросов не вызывает проблем.

**Ожидаемый эффект:** Экономия 30-45 секунд на тему с несколькими chunks.

| Параметр | До | После |
|----------|-----|-------|
| CHUNK_SIZE | 70 000 | 100 000 |

| Задержки между запросами | 15 сек × N | 0 |
| Ожидаемое время LLM на тему 180K | ~15 мин | ~4-5 мин |
