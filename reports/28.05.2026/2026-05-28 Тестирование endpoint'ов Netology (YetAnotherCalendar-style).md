## Рекомендации для StudyCore

### 🔥 Приоритет: Критический

1. **Заменить Playwright-авторизацию на POST /sign_in**
   - Скорость: 1–2 сек vs 10–15 сек
   - Надёжность: нет headless-детекции, race conditions
   - Fallback: если POST вернёт 401/403/429 — автопереключение на Playwright

2. **Использовать `/programs/{id}/schedule` для получения структуры дисциплины**
   - Заменить скрейпинг HTML через Playwright на API-запросы
   - `lesson_items` содержат `type`, `title`, `path`, `passed`
   - `path` — прямой путь к материалу (можно запросить контент)

3. **Парсить дедлайны из `title`**
   - Поле `deadline` в `lesson_item` часто `null`
   - Regex: `(\d{2})[^\w]+(\d{2})[^\w]+(\d{2,4})` для `DD.MM.YY`
   - YetAnotherCalendar уже реализовал это в `LessonTask.deadline_validation`

### ⚡ Приоритет: Высокий

4. **Использовать `/professions/{id}/schedule` для списка дисциплин**
   - 23 модуля бакалавриата с `start_date`/`finish_date`
   - Уже используется StudyCore для валидации семестров — подтверждено стабильное

5. **Кэшировать cookies**
   - `_netology-on-rails_session` живёт ~7 дней
   - Хранить в `backend/netology_cookies/netology_cookies.json` (как сейчас)
   - Проверять валидность перед запросом, обновлять при 401

6. **HTTP/2 в httpx**
   - `AsyncClient(http2=True)` — мультиплексирование
   - Особенно важно для параллельной загрузки 23 дисциплин

### 📋 Приоритет: Средний

7. **TaskGroup для параллельных запросов**
   - `asyncio.TaskGroup` (Python 3.11+) — параллельная загрузка всех дисциплин
   - Ускорение: с ~30 мин до ~2–3 мин на бакалавриат

8. **Retry декоратор**
   - `@reretry.retry(exceptions=httpx.TransportError, tries=5, delay=3)`
   - Вместо ручных циклов в `netology_api_client.py`

## Итог

**Все 7 endpoint'ов работают.** Ключевое открытие — `/programs/{id}/schedule` возвращает полную структуру дисциплины с lesson_items (attachment, text, video, webinar, task, test). Это позволяет **полностью заменить скрейпинг** на API-запросы.

**Авторизация через POST /sign_in подтверждена** — получаем валидную сессию за 230 мс без браузера.

**Ближайший шаг:** адаптировать `netology_api_client.py` для использования POST-логина и `/programs/{id}/schedule` вместо Playwright-скрейпинга.
