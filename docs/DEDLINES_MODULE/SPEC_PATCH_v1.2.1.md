## 3. Проблемы и решения

### 3.1 🔴 Название модуля (issue #46)

**Решение:** Заменить «Ближайшие дедлайны» → «Ближайшие события» в `Home.tsx:248`.

### 3.2 🔴 Кнопка «Все» в заголовке (issue #47)

**Решение:** Убрать кнопку из заголовка, добавить «Показать все (N)» внизу модуля.

### 3.3 🔴 Лишние бейджи (issue #48)

**Решение:**
- «Выполнено» только если событие прошло (`isEventPast`)
- Плюрализация: «1 вариант», «2 варианта», «5 вариантов»

### 3.4 🔴 Дублирование событий (issue #49)

**Корень:** Race condition при sync + `item_count` считал дубли из двух API.

**Решение:**
- Backend: unique constraint + upsert + cleanup
- Frontend: дедупликация + guard + setTimeout вместо setInterval
- Схема: `item_count` считает уникальные `id` в `raw_items`

### 3.5 🟡 Группировка по программе (issue #50)

**Проблема:** Название программы дублируется — уже есть внутри DeadlineCard.

**Решение:** Убрать Map-группировку в Home.tsx, плоский список шейпов.

### 3.6 🟡 BottomNav label (issue #51)

**Решение:** «Дедлайны» → «События» в `BottomNav.tsx`.

### 3.7 🟡 Бесшовная синхронизация (issue #52)

**Требование:** Загрузка видна только при первой авторизации. Далее — прозрачное обновление.

**Решение:**
1. `staleTime: Infinity` — данные не устаревают автоматически
2. `refetchOnWindowFocus: false` — не refetch при возврате на вкладку
3. `doSilentSync` → `refetch()` вместо `invalidateQueries`
4. `doSync` → `refetch()` вместо `invalidateQueries`

**Ограничение:** При обновлении страницы (F5) спиннер остаётся — это первая загрузка, React Query кэш сбрасывается. Бесшовность работает только в рамках одной сессии без перезагрузки.

### 3.8 🟢 python-dotenv warnings (issue #53)

**Решение:** Добавить `#` к каждой строке инструкций в `.env`.

### 3.9 🔴 События прошлых лет в кэше (issue #54)

**Проблема:** На странице событий среди актуальных появляются события сентября 2025 года.

**Корень:** React Query кэш содержит старые данные. `staleTime: Infinity` + перезапуски бэкенда = кэш никогда не обновляется.

**Решение:**
1. `queryClient.clear()` при старте приложения (App.tsx)
2. `isEventUpcoming()` — фронтенд-фильтрация прошедших событий
3. Retry (3 попытки) в `doSilentSync` при ошибке соединения
4. `gcTime: 10 минут` — автоматическая очистка после размонтирования

**Файлы:** `frontend/src/App.tsx`, `frontend/src/hooks/useDeadlines.ts`
