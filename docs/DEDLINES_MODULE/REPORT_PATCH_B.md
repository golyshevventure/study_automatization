## Что сделано

### 1. Авто-синхронизация при входе на страницу

В `Deadlines.tsx` добавлен `useEffect`:
- При монтировании проверяет `localStorage.getItem("deadlines_last_sync")`
- Если с последней синхронизации прошло > 5 минут — вызывает `doSync()`

### 2. Интервал 30 минут

- `setInterval` с периодом `30 * 60 * 1000` мс
- Cleanup при unmount (`clearInterval`)
- Синхронизация происходит даже если вкладка оставалась открытой

### 3. Timestamp последней синхронизации

- Хранится в `localStorage` (ключ `deadlines_last_sync`)
- Отображается под заголовком «Ближайшие события»
- Формат:
  - < 1 мин — «Только что»
  - < 1 ч — «N мин назад»
  - < 24 ч — «N ч назад»
  - иначе — дата-время

### 4. Ручная синхронизация

- Кнопка ↻ продолжает работать
- При нажатии обновляет timestamp
