## 1. Цель

Полностью переработать модуль «Ближайшие события / Дедлайны / События» в полноценный **Календарь** с сеточным UI (месяц/неделя), цветовой кодировкой, фильтрами и деталями событий.

**Проблемы текущего модуля v1.2:**
- Список событий не даёт визуального понимания загруженности
- Старые события из кэша мешают восприятию
- Баг парсинга дат (+1 год при просрочке)
- Нет масштаба «месяц» — нельзя оценить загруженность наперёд

## 2. Пользовательские истории (User Stories)

### US-1: Месячный обзор
> **Как** студент,  
> **я хочу** видеть календарь на текущий месяц в виде сетки 7×6,  
> **чтобы** понимать, насколько загжен каждый день и когда есть «окна» для отдыха.

**Критерии приёмки:**
- Сетка отображает все дни месяца + дни соседних месяцев для заполнения краёв
- Текущий день выделен цветом
- В ячейке дня отображаются точки/бейджи событий (макс. 3-4)
- Пустые дни визуально отличаются от загруженных

### US-2: Недельный обзор
> **Как** студент,  
> **я хочу** переключиться на вид «неделя»,  
> **чтобы** детально видеть расписание занятий и дедлайнов на ближайшие 7 дней.

**Критерии приёмки:**
- 7 колонок (Пн–Вс), строка заголовков с датами
- Отдельная строка «Дедлайны» (как в YetAnotherCalendar) — дедлайны за день внизу
- События с временем отображаются в хронологическом порядке
- Свайп/прокрутка между неделями

### US-3: Цветовая кодировка по типу
> **Как** студент,  
> **я хочу** видеть разные цвета у разных типов событий,  
> **чтобы** одним взглядом отличать вебинар от зачёта и от теста.

**Критерии приёмки:**
| Тип | Цвет |
|-----|------|
| Вебинар / Занятие | Синий #3B82F6 |
| Тест | Жёлтый #F59E0B |
| Зачёт | Красный #EF4444 |
| Экзамен | Красный #EF4444 (ярче) |
| Дедлайн (ДЗ) | Оранжевый #F97316 |
| Консультация | Фиолетовый #B794F6 |

### US-4: Детали события по клику
> **Как** студент,  
> **я хочу** кликнуть на событие и увидеть полную информацию,  
> **чтобы** не искать детали в других местах.

**Критерии приёмки:**
- Модальное окно / BottomSheet с:
  - Названием события
  - Датой и временем
  - Программой / курсом
  - Типом (иконка + текст)
  - Ссылкой на вебинар/задание (если есть)
  - Статусом (пройдено / предстоит)

### US-5: Фильтрация по типу
> **Как** студент,  
> **я хочу** отфильтровать календарь по типу событий,  
> **чтобы** видеть, например, только зачёты и экзамены.

**Критерии приёмки:**
- Фильтр: Все / Занятия / Работы / Контроль (как сейчас)
- Применяется к обоим видам (месяц и неделя)
- Фильтр сохраняется в localStorage

### US-6: Навигация по периодам
> **Как** студент,  
> **я хочу** листать месяцы/недели кнопками или свайпом,  
> **чтобы** планировать далеко вперёд.

**Критерии приёмки:**
- Кнопки «← →» для переключения
- Свайп влево/вправо на мобильном
- Быстрый переход к сегодняшнему дню
- Загрузка событий для нового периода — бесшовная

### US-7: Виджет на главной
> **Как** студент,  
> **я хочу** на главной видеть мини-календарь на текущую неделю,  
> **чтобы** не заходить на отдельную страницу для быстрого просмотра.

**Критерии приёмки:**
- Мини-календарь: 7 дней в ряд (горизонтально)
- Только точки/индикаторы наличия событий
- Клик переходит на страницу Календаря

### US-8: Корректные даты
> **Как** студент,  
> **я хочу** видеть реальные даты событий,  
> **чтобы** просроченные задания не отображались как будущие.

**Критерии приёмки:**
- Парсер дат не сдвигает +1 год при просрочке
- Прошедшие события не показываются в календаре (или показываются серым/зачёркнутым)
- Бэкенд фильтрует `event_date >= today`

### US-9: Бесшовная синхронизация
> **Как** студент,  
> **я хочу** видеть актуальные данные без спиннера,  
> **чтобы** пользоваться календарем комфортно.

**Критерии приёмки:**
- Фоновый sync каждые 30 мин
- При обновлении данных — мягкое обновление без миганий
- При ошибке соединения — retry 3 раза

### US-10: Экспорт (опционально, v2.1)
> **Как** студент,  
> **я хочу** экспортировать события в .ics,  
> **чтобы** добавить их в Google/Apple Calendar.

## 3. Архитектура

### 3.1 Backend

```
GET /api/calendar/month?year=2026&month=6&filter=all
→ { year, month, filter, days: { "2026-06-08": [events], ... }, total }

GET /api/calendar/week?year=2026&week=23&filter=all
→ { year, week, filter, days: { "2026-06-08": [events], ... }, total }
```

**Изменения:**
- Новый router `backend/routers/calendar.py`
- Новый service `backend/services/calendar_service.py` — группировка событий по дням
- Фикс `netology_schedule_service.py` — убрать +1 год
- Удалить старый `deadline_service.py` / `deadline_merger.py` (или оставить для совместимости)

### 3.2 Frontend

```
src/
  pages/
    Calendar.tsx          # Главная страница календаря
  components/calendar/
    CalendarMonthView.tsx # Сетка месяца
    CalendarWeekView.tsx  # Сетка недели
    CalendarDayCell.tsx   # Ячейка дня
    EventDetailModal.tsx  # Модальное окно события
    CalendarHeader.tsx    # Заголовок с навигацией
    CalendarFilterBar.tsx # Фильтры
    MiniCalendar.tsx      # Виджет для Home
  hooks/
    useCalendar.ts        # Загрузка данных за период
```
